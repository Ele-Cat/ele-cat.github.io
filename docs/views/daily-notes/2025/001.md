# 开发环境搭建

## 一. 前端开发环境搭建

### 01. Node.js 安装与配置

使用[nvm](https://github.com/coreybutler/nvm-windows/releases)安装 Node.js（推荐），或直接安装[Node.js](https://nodejs.cn/download/)

```bash
nvm install 18.16.0
nvm use 18.16.0

# 验证安装
node -v
npm -v

# 安装yarn
npm install -g yarn
# 安装pnpm
npm install -g pnpm
```

### 02. Git 安装与配置

1. 下载[安装包](https://git-scm.com/downloads)并运行安装

```bash
git --version
```

2. 初始配置

```bash
# 1. 设置用户信息（必须）
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

3. 图形化工具安装

   1. [TortoiseGit](https://tortoisegit.org/download/)
   2. [SourceTree](https://www.sourcetreeapp.com/)
   3. [GitHub Desktop](https://desktop.github.com/)

4. 命令

```bash
# 新建Git仓库
mkdir my-project
cd my-project
git init

# 克隆现有仓库
# HTTPS方式
git clone https://github.com/username/repo.git
# SSH方式（推荐）
git clone git@github.com:username/repo.git
# 指定目录
git clone git@github.com:username/repo.git my-folder
```

5. .gitignore 配置

```bash
# 依赖目录
node_modules/
dist/
build/

# 环境文件
.env
.env.local

# 编辑器文件
.vscode/
.idea/

# 系统文件
.DS_Store
Thumbs.db

# 日志文件
*.log
```

6. 常用命令，[查看更多](../../note/git.html)

```bash
# 查看远程仓库
git remote -v

# 设置远程仓库地址
git remote add origin git@github.com:username/repo.git

# 设置项目专用用户名（覆盖全局配置）
git config user.name "Project Specific Name"

# 设置默认分支名为main
git config --global init.defaultBranch main

# 设置文件大小写敏感
git config --global core.ignorecase false
```

## 二. 后端开发环境搭建

### 01. Java 开发环境搭建

1. JDK 安装

   1. 下载 JDK （LTS 版本）：

      - 官网下载：https://www.oracle.com/java/technologies/downloads
      - 选择 Windows x64 Installer

   2. 运行安装程序：

      - 默认安装路径（建议）：`C:\Program Files\Java\jdk-x`

   3. 配置环境变量：

      ```bash
      # 1. 新建系统变量
      JAVA_HOME = C:\Program Files\Java\jdk-x

      # 2. 编辑Path变量，添加：
      %JAVA_HOME%\bin
      ```

   4. 验证安装：

      ```cmd
      java -version
      javac -version
      ```

2. IDE 安装与配置（IntelliJ IDEA）

   1. 下载安装：

      - 官网下载：https://www.jetbrains.com/idea/download/
      - 选择 Ultimate（付费）或 Community（免费）版

   2. 首次运行配置：

      - 选择刚刚安装的 JDK x 作为默认 JDK
      - 安装常用插件：
        - Lombok
        - Spring Boot
        - Database Tools
        - Maven/Gradle

   3. 下载[Maven](https://maven.apache.org/download.cgi)并配置：

      ```bash
      # 修改settings.xml（路径：~/.m2/settings.xml）
      <settings>
        <mirrors>
          <mirror>
            <id>aliyun</id>
            <name>Aliyun Maven</name>
            <url>https://maven.aliyun.com/repository/public</url>
            <mirrorOf>central</mirrorOf>
          </mirror>
        </mirrors>
      </settings>
      ```

### 02. MySQL 数据库安装

1. MySQL 安装

   1. 下载 MySQL Installer：

      - 官网下载：https://dev.mysql.com/downloads/installer/
      - 选择版本：MySQL Community Server 8.0+

   2. 运行安装程序：

      - 选择"Developer Default"安装类型
      - 设置 root 密码（务必记住）
      - 配置服务端口（默认 3306）
      - 勾选"Add firewall exception for this port"
      - 完成安装

   3. 验证安装：

      ```bash
      mysql -u root -p
      # 输入密码后应进入MySQL命令行
      ```

2. 数据库客户端工具安装

   - [Navicat Premium](https://www.navicat.com.cn/download/navicat-premium)
